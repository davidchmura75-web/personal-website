Tipping Point

Ping pong balancing system using PID control

Watch on YouTube

Notes

Tipping Point USA is not to be confused with "Turning Point USA", the political organization. This is a project I decided to make because I learned about PID controllers and wanted to make a live demo for these systems. The road to a final product was not smooth, with many issues, from dealing with a 3D print clog to dealing with component failures. One of the issues we had was with the distance sensor not reading the ping pong ball at longer distances. To solve this issue, I added one on each side and implemented logic to choose which sensor to use for the reading. But through late nights and perseverance, I was able to finish the project.
